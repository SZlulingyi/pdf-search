# 知索需求与实现对照表

状态说明：

- **已完成**：当前系统可运行。
- **外部依赖**：由 RAG 同事或 LLM 团队提供。
- **部分完成**：主流程可用，但依赖 RAG 返回更完整字段。
- **不做**：不属于当前客户交付范围。

| 客户需求 | 当前实现 | 状态 | 备注 |
|---|---|---|---|
| 登录 | 本地用户登录，密码 scrypt 加盐哈希 | 已完成 | 管理员可创建和删除用户 |
| 数据隔离 | 每个用户独立 RAGFlow 数据集，跨用户访问返回 403 | 已完成 | 已实测隔离 |
| PDF 录入 | 原始 PDF 上传、解析、切块、向量化、入库 | 已完成 | 前端不再拆页，RAGFlow 保留原文件并统一切块 |
| Word 录入 | DOCX 上传、解析、切块、向量化、入库 | 已完成 | 已端到端验证 |
| Excel 录入 | 上传入口已按最新要求移除 | 已移除 | 检索结果仍可导出 XLSX |
| 全页信息采集到本地数据库 | RAGFlow 本地栈保存原文、页码、chunk、positions；前端支持 PDF 原页和 bbox | 部分完成 | block/asset/confidence 完整字段依赖 RAG 提供 |
| 大模型本地化 | 接入 OpenAI-compatible 接口 | 外部依赖 | LLM 部署、GPU 和模型运维由外部团队负责 |
| 目标 1：全数据库关键字检索 | ES 精确检索，支持编号、金额、日期和中文 n-gram | 已完成 | Chat 内执行 |
| 目标 1 输出汇总表和 PDF | 命中表格、CSV、XLSX、打印/PDF、原文 PDF 查看 | 已完成 | 输出格式可按客户要求调整 |
| 目标 2：文本相似性检索 | BGE-M3 语义召回 | 已完成 | Chat 内执行 |
| 目标 2 输出疑似段落和差异 | 相似段落并排、金额/日期/编号等差异、风险说明 | 已完成 | LLM 分析，失败时规则回退 |
| 目标 3：格式转写 | 根据文字描述生成标准文档 | 已完成 | 项目台账、合同摘要、发票汇总、标准文档 |
| 目标 3 输出格式 | Markdown、DOCX、XLSX、打印/PDF | 已完成 | DOCX/XLSX 是真实 Office 文件 |
| Chat Agent 统一入口 | 上传、检索、比对、转写都在同一个 Chat | 已完成 | 无独立工具页 |
| 多会话 | 新建、切换、停止生成 | 已完成 | 会话并行执行 |
| 原始 PDF 查看 | PDF.js 站内原页渲染和位置高亮 | 已完成 | 支持多命中区域 |
| 服务状态 | 页面顶部显示服务可达状态 | 已完成 | 不做复杂监控 |
| 文件过滤、A/B 独立入口、任务中心、审计 UI、模型设置 UI | 已从用户界面移除 | 不做 | 非客户必需 |
| 备份恢复、SSO、多租户、模板审批、Word/Excel 预览 | 未实现 | 不做 | 明确排除 |
