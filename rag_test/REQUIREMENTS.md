# 知索知识库产品 v2 需求说明

## 1. 总目标

建设一个本地化部署的知识库与 AI Agent 系统，支持：

- 大模型本地化
- PDF、Word、Excel 录入
- 全页信息采集并写入本地数据库
- 全数据库关键字检索
- 文本相似性检索与数据差异分析
- 按文字描述进行标准格式转写

系统原则上不依赖云端服务。远程大模型只能作为可选的备用通道，不是默认运行依赖。

## 2. 本地化要求

### 2.1 模型本地化

需要本地运行：

- 生成式大模型：默认用于问答、汇总、差异说明、格式转写
- 向量模型：BGE-M3
- OCR/版面模型：PaddleOCR / PP-StructureV3

建议部署方式：

- Ollama 或 vLLM 提供本地 OpenAI-compatible API
- 推荐模型规模根据机器资源确定
- 远程 DeepSeek 配置保留为可选备用，不作为默认依赖

### 2.2 数据本地化

原始文件、解析结果、索引、向量和任务记录全部保存在本地：

- 原始文件：本地对象存储
- 全文和向量：Elasticsearch/OpenSearch
- 元数据和任务：MySQL/PostgreSQL
- 缓存和队列：Redis
- OCR/版面模型：本地 PaddleOCR 服务
- 生成式模型：本地模型服务

## 3. 文档录入

### 3.1 支持格式

第一阶段至少支持：

- PDF
- DOC / DOCX

> 最新决策：暂不开放 XLS / XLSX 上传入口；检索结果仍保留 XLSX 导出能力。

后续可以扩展：

- PPT / PPTX
- HTML
- TXT / Markdown
- 图片和扫描件

### 3.2 全页信息采集

每一页需要采集并保存：

- 原始文件
- 页码
- 页面截图
- 页面文字
- 文本块、标题、段落
- 表格及单元格
- 图片及图片位置
- 图表及图表描述
- 公式、印章、页眉、页脚
- 每个元素的 bbox 坐标
- OCR 置信度
- 来源文件、页、块 ID
- 文档类型和业务字段

### 3.3 入库结构

建议使用统一逻辑文档模型：

- document：原始文件
- page：页面
- block：文本块、标题、段落、表格、图片等
- table：表格结构
- asset：图片、图表和页面截图
- field：发票号、金额、日期等结构化字段
- chunk：可检索片段
- embedding：向量
- job：解析任务
- output：检索、比较、转写输出

原始 PDF 整份入库，由 RAG 服务在内部切分检索 chunk，保留原始文件和全局页码。

## 4. AI Agent 功能一：全数据库关键字检索

### 4.1 输入

- 一个或多个关键字
- 可选字段过滤条件
- 可选文件类型、日期、文档类型范围

### 4.2 检索行为

- 全数据库精确文本检索
- 数字、编号、金额、日期优先精确匹配
- 支持短语、同义词和 OCR 容错
- 返回原文位置、页码、bbox 和证据截图

### 4.3 输出

默认输出：

- XLSX 汇总表
- 对应 PDF 证据文件或页面合辑
- 可选 DOCX 报告

汇总表建议字段：

- 序号
- 文件名
- 页码
- 命中关键字
- 命中原文
- 上下文
- 匹配类型
- 匹配分数
- 来源文件 ID
- 页面截图路径
- bbox

## 5. AI Agent 功能二：文本相似性检索与差异分析

### 5.1 输入

- 一个或一组参考文本
- 或者选择两个文档/章节进行比较
- 可指定比较范围和字段

### 5.2 检索行为

- BGE-M3 语义相似检索
- 全文关键词检索作为辅助
- 召回疑似相同、相似、冲突或异常段落
- 对金额、日期、数量、名称、编号等进行数据差异识别
- 区分：
  - 完全一致
  - 语义相似
  - 数值不一致
  - 名称不一致
  - 缺少内容
  - 可能冲突

### 5.3 输出

默认输出：

- XLSX 差异表
- DOCX 对比报告
- 可选 JSON/CSV

差异表建议字段：

- 序号
- 来源 A
- 来源 B
- A 页码
- B 页码
- A 原文
- B 原文
- 相似度
- 差异类型
- 差异字段
- A 数值
- B 数值
- AI 说明
- 风险等级

## 6. AI Agent 功能三：格式转写

### 6.1 输入

- 用户文字描述
- 可选参考文档
- 可选目标模板
- 文档类型

### 6.2 行为

基于本地生成式模型，将文字描述转写为指定类型的标准格式：

- 标准合同
- 标准申请表
- 标准报告
- 标准台账
- 标准汇总表
- 其他业务模板

### 6.3 输出

根据文档类型输出：

- DOCX
- XLSX
- PDF
- JSON

要求：

- 保留用户原始事实
- 不编造未提供的业务数据
- 标准模板可配置

## 7. 页面交互

主界面只保留一个统一的 AI 助手，不再把检索、相似比对和格式转写拆成独立工具页。用户直接在同一个会话里描述目标，系统自动判断并选择精确检索、语义检索、差异分析或格式转写。

每条 AI 回答下方提供统一交付面板：

- 精确检索：汇总表、原文高亮、来源文件、页码、CSV/Excel 导出
- 相似比对：疑似段落并排、数据差异高亮、差异表导出
- 格式转写：模板选择、标准文档预览、Markdown/Word 下载
- 原文证据：直接打开对应 PDF，并在可用时定位到页码

资料库使用右侧抽屉，负责：

- PDF/Word/Excel 上传
- 解析和入库进度
- 失败重试
- 逻辑文档展示
- 分片详情
- 删除操作
- 页面状态刷新后保持

## 8. 部署结构

```text
知索前端
  ↓
知索本地网关
  ├─ 本地 LLM 服务
  ├─ RAGFlow
  ├─ PaddleOCR / PP-StructureV3
  ├─ BGE-M3 / TEI
  ├─ Elasticsearch
  ├─ MySQL / PostgreSQL
  ├─ Redis
  └─ MinIO / 本地文件存储
```

## 9. 交付范围收敛

本项目只保留能直接影响三条业务链路的能力：

### 9.1 必须保留

1. 文档录入
   - PDF、Word、Excel 上传
   - 自动解析、切块、向量化
   - 解析进度、失败重试、删除
   - 原始文件保存和原文查看

2. 精确检索
   - 全库关键字、编号、金额和日期查找
   - 结果汇总表
   - 来源文件、页码和原文证据
   - CSV、XLSX、PDF 输出

3. 相似检索与差异分析
   - BGE-M3 语义召回
   - 相似段落和来源展示
   - 金额、日期、编号、名称等差异汇总
   - 差异表和对比报告输出

4. 格式转写
   - 按模板生成标准文档
   - 模板名称和结构要求可配置
   - Markdown、DOCX、XLSX、PDF 输出

5. 基础设施
   - 登录
   - 单知识库
   - 会话
   - 服务健康状态
   - LLM OpenAI-compatible 接口配置

### 9.2 明确不做

以下能力不进入本轮范围，除非以后单独提出：

- 备份与恢复
- CPU、GPU、内存和队列监控
- SSO、LDAP、OIDC
- 字段级权限和复杂审批
- 模板版本管理和审批流
- Word/Excel 站内预览
- 转写结果自动回写知识库
- 服务端原生 PDF 排版引擎
- 多租户隔离
- 高级审计检索、导出和防篡改
- 独立的向量数据库、重排服务和额外基础设施

## 10. 必须完成的外部接口

LLM 团队负责：

- 部署 OpenAI-compatible LLM 服务
- 提供 Base URL、模型名、API Key、并发和上下文限制

RAG 同事负责：

- 提供稳定的精确检索和语义检索接口
- 返回文件名、页码、原文和位置
- 如支持复杂页面，再返回 block、bbox、元素类型和置信度

知索负责：

- 前端、网关、LLM 适配
- 结果结构化、差异分析、格式转写和文件输出
- 登录、会话、基础权限、审计和任务状态
